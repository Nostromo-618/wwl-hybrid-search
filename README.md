# wwl-hybrid-search

Headless hybrid search for Weekend Web Labs. Fuzzy retrieval is Fuse.js; semantic retrieval is Transformers.js. The host injects both libraries and serves a prebuilt index.

Not published. [Labs](https://github.com/nostromo-618/weekend-web-labs) consumes it as a sibling (`link:../wwl-hybrid-search`).

```bash
pnpm install && pnpm build
```

Spec: [openspec/](./openspec/).
